## 重大な注意点

現時点で、**正式名称・住所・棟情報の多くは公式/ポータルサイトから取得しているため、`publication_allowed = false` です。**

PLATEAU や Address Base Registry からは「建物外形・位置」「住所構成」は取得できますが、**マンション名称自体を無料で安全に公開できるオープンデータはありません。**

そのため、MVP の Public Mansion Page は以下のどちらかが必要です。

1. 各マンション名・詳細の公開に対する法務/利用規約上の承認を取得する
2. 該当属性を `publication_allowed = false` のまま、`noindex` 状態でページのみ作成する

差し替えはせず、本件を報告します。
